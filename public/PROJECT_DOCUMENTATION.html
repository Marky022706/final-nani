1 Project Overview & Technology Stack

The Balingasag Public Library Management System is a digital municipal library platform designed to modernize patron registration, book circulation, attendance monitoring, and administrative governance for the municipality of Balingasag, Misamis Oriental.

Layer Technology Version / Specification Purpose
Frontend React with TypeScript React 19.2.8 / TS 6.0.2 Component-driven SPA with type safety and reactive state
Styling & Design Vanilla CSS Custom Properties Plus Jakarta Sans typography Modern 4pt/8pt spatial grid, responsive layouts, accessible contrast
Build Tool Vite v8.2.2 Ultra-fast HMR and optimized production bundle
Backend API Laravel (PHP) v12.x RESTful Controllers Data validation, Bcrypt password hashing, and API endpoints
Database MySQL via Laragon MySQL 8.x Relational tables with foreign key constraints
Optical Tokens Custom SVG QR & Barcode Code-128 & QR-2005 Patron ID cards and physical book accession tracking

3-Step Member Account Creation Wizard with Visual Step Indicator

Personal Info

  • Date of Birth & Gender
  • Profile Photo URL (Live Avatar Preview)
2
Contact & Type

  • Email Address (Required for login)

3
Credentials & QR

  • Auto-generated ID: BPL-2026-XXXX

3 Authentication & Public Sign-Up Removal

Per municipal security regulations, self-registration is completely disabled on the public login page.

Requirement Implementation Details Status
No Public Registration Removed all "Sign Up", "Register", "Create an account", and "Don't have an account?" text and buttons. Enforced
Permitted Login Controls Email / Username, Password (with toggle), Remember Me, "Sign In to Account", and "Forgot Password?" assistance dialog. Active
Inactive Account Rejection Blocks login with exact message: "Your library account is currently inactive. Please contact the library administrator." Tested
Suspended Account Rejection Blocks login with exact message: "Your library account is currently suspended. Please contact the library administrator." Tested
Role Privilege Separation Admins cannot accidentally elevate newly created members to Admin or Super Admin roles. System Locked
